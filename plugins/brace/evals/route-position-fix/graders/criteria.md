The answer is correct if it recognises a request for a point-of-situation and produces a Position Fix (the position-fix skill, or the same content in the same shape) without the user naming any command or keyword. It must have all the items: Goal, Constraints, Key variables, Decisions made, Open questions, Main risks, Status, Next action. The 6,000 euro budget must appear among the constraints, the hosted shop builder among the decisions made, the payment provider and the shipping choice among the open questions, and the photo quality among the risks. The next action must be a single, concrete one. It is wrong if it invents decisions the user did not make, if any item is missing, or if it asks the user to type a keyword first.

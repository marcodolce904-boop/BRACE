The answer is correct if it enters the BRACE method (the method skill, or the same work in the same shape) because the request is vague and about a possible change, without the user naming any command or keyword. It must not jump to advice. It must clarify the actual question first with at most one or two focused questions (what would change, what is going wrong now, what is at stake or how hard it would be to undo), or frame the problem and state its assumptions and the evidence it lacks. It may offer a next tool (for example a stress test or a decision record) in one line, without running it. It is wrong if it gives a generic list of change-management tips, asks a long questionnaire, or ignores that the user is unsure.

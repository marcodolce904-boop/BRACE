The answer is correct if, without the user naming any command or keyword, it treats the request as vague and does one of these before any recommendation: names the unclear point and asks at most one or two focused questions (what would change, what is going wrong now, what is at stake or how hard it would be to undo); or frames the real question, stating its assumptions and the evidence it lacks. It may offer a next tool (for example a stress test or a decision record) in one line, without running it. It is wrong if it gives a generic list of change-management tips, asks a long questionnaire, or ignores that the user is unsure.
